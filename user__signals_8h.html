Detailed Description

Output user action signals on the serial and bluetooth links.

Each signal is a single line: '$' + name + ':' + values separated by ':' + "\r\n". The '$' prefix separates them from timestamped logs ("<time>> ..."). Names are short to avoid saturating slow outputs (BLE). This format is a public interface for external apps: do not change existing signals, only add new ones.

  • "$brgt:<0-1024>" brightness changed
  • "$mode:<group>:<mode>" active mode changed
  • "$ramp:<0-255>" custom ramp changed
  • "$ind:<0-2>" indicator level changed (see logic::indicator::set_brightness_level)

Rate limiting: each signal is sent at most once every signalIntervalMs. A change that arrives while the interval is running is not sent at once, only the latest value is kept and sent when the interval ends.

Call user_signals::loop() regularly (more often than signalIntervalMs) so that pending values get sent.
