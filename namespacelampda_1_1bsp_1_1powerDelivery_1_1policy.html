◆ hardResetUnplugDeglitch_ms

constexpr uint32_t lampda::bsp::powerDelivery::policy::hardResetUnplugDeglitch_ms = 3000
staticconstexpr

During a hard reset, the source drops VBUS: tSafe0V (650ms) + tSrcRecover (1000ms) + tSrcTurnOn (275ms) ~= 1.9s. VBUS can be lost this long before the source is considered unplugged. This limit does not depend on the PD state machine: if it stalls in a hard reset state, an unplug must still be detected (issue #642). Also used for a power role swap: old source turn off (tPSSourceOff, 920ms) + new source turn on (~400ms).

◆ maxPdNegociationWait_ms

constexpr uint32_t lampda::bsp::powerDelivery::policy::maxPdNegociationWait_ms = 8000
staticconstexpr

After this delay, the standard port fallback does not wait for the PD negociation anymore. It is only a guard against a stuck state machine: every negociation state has its own timeout. Worst case of a late negociation: CC debounce (200ms) + caps wait (600ms) + soft reset (30ms)

  • 2 * (hard reset recovery (650ms + 1275ms) + caps wait (600ms)) ~= 5.9s
