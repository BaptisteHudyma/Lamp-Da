Default behaviors that can be linked to a click count.

Enumerator
Favorite 

click: jump to the favorites. hold: add or remove a favorite

QuickNavigation 

click: jump to the first mode

Sunset 

hold: start or extend the sunset timer

CustomRamp 

hold: configure the custom ramp of the mode

Indicator 

click: next indicator brightness. hold: cycle the indicator brightness

Scroll 

hold: scroll across modes and groups

None 

no behavior, keep this value last
