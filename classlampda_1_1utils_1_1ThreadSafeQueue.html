Detailed Description

template<typename T, size_t N>
class lampda::utils::ThreadSafeQueue< T, N >

Fixed capacity FIFO queue, guarded by a mutex. Push and pop can be called from any thread, but not from an interrupt. The lock is only held while copying an item, never while the caller handles it.
